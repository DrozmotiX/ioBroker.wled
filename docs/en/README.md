# WLED – Documentation

The WLED adapter connects LED controllers running the WLED firmware to ioBroker: it finds your devices and lets you control colors, effects, presets and segments.

This documentation is organised around the questions users have asked in the forum and in the issues. Every heading is one of those questions.

- **[Getting started](01.erste-schritte/README.md):** Install WLED and connect your first device.
- **[How-to guides](02.anleitungen/README.md):** Guides by task: finding devices, controlling light and effects, managing segments, working with scripts and VIS.
- **[Reference](03.referenz/README.md):** All settings, generated states, commands and log messages to look up.
- **[Troubleshooting](04.fehlerbehebung/README.md):** The most common error messages and connection problems, and how to fix them.
- **[Background](05.hintergrund/README.md):** A short explanation of how the adapter talks to your devices.
